# 🎮 Консольная игра "Виселица" (Hangman)

Классическая игра "Виселица", реализованная на Java с использованием объектно-ориентированного подхода. Приложение работает в консольном интерфейсе, предлагает игроку отгадать загаданное слово, вводя буквы по одной.

## 📋 Описание

Цель игры — угадать скрытое слово, называя буквы по очереди. За каждую неверно названную букву добавляется элемент к рисунку виселицы. Если рисунок будет завершен до того, как слово будет угадано, игрок проигрывает.
